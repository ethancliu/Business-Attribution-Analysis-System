# 用户口碑与退款诊断

## 一、口碑诊断的核心：看占比，不看绝对量

评论总量上涨是正常的经营波动，**负面评论占比**上升才是口碑恶化的信号。

| 信号 | 含义 |
| --- | --- |
| 负面占比上升 + 评论总量平稳 | 不满集中爆发，最需要立刻介入 |
| 负面占比平稳 + 评论总量上升 | 业务在增长，属正常 |
| 负面占比上升 + 评论总量上升 | 增长伴随品质问题，需要评估增速是否可持续 |

**预警线**：负面评论占比超过 20%，或相对基准期上升超过 50%。

## 二、差评标签的读法

差评标签呈**单点爆发**还是**全面扩散**，决定了处置方式：

- **单点爆发**（某个标签占比从 5% 涨到 40%）→ 某类问题集中爆发，
  通常可定位到具体商品或批次，处置快、见效快。
- **全面扩散**（所有标签均匀上升）→ 通常是服务体验或履约系统性问题，
  需要跨部门整改。针对单一标签整改无效。

本系统演示数据中，差评集中于「描述不符」，属于典型的单点爆发，
且与商品目录质量问题（标题夸大、主图与实物不符、属性缺失）互为印证。

## 三、退款诊断：责任归属是分水岭

退款原因必须区分**责任归属**：

| 责任方 | 典型原因 | 处置方向 |
| --- | --- | --- |
| 商品责任 | 质量问题、描述不符、发错货 | 供应链整改、页面修正、下架 |
| 物流责任 | 破损、超时、丢件 | 更换承运商、加固包装 |
| 用户责任 | 七天无理由、买错了、不想要了 | 优化尺码表、加强详情引导 |

**判断方法**：商品责任退款占比上升 → 问题在商品侧；
非商品责任上升 → 问题在履约或用户预期管理。

若商品责任退款占比同时上升、且退款原因集中在单一原因上，
基本可以确定是**批次质量问题**或**页面描述失真**，两者处置方式不同：
前者下架整改，后者改页面即可。

## 四、退款率上升的连带影响

退款不只是损失一笔收入，它会连锁触发：

1. 店铺权重下降（平台算法惩罚退款率高的店铺）
2. 自然流量减少 → 流量成本上升 → ROAS 恶化
3. 库存二次损失（退货商品可能需要折价处理）
4. 售后人力成本上升 → 平均处理时长增加 → 二次投诉

因此退款率是**不能拖的指标**，必须在扩散前拦截。

## 五、拦截机制

1. **新品上架前 50 单人工回访**：在小规模阶段发现描述不符问题，
   避免差评在大流量阶段集中爆发
2. **售后处理时长压缩到 24 小时以内**：处理滞后本身会引发二次投诉
3. **商品责任退款率单 SKU 监控**：超过类目均值 2 倍进入观察名单
4. **评论区关键词聚类**：每日对新出现的差评做标签聚类，
   新标签出现即人工审阅

## 六、常见误判

- **把退款率上升归因为「用户变挑剔」**：这是最危险的归因，
  因为它导向「什么都不做」。正确做法是先看责任归属。
- **只处理退款不处理根因**：退款是症状，责任归属才是病因。
- **忽略退款原因的结构变化**：退款总量不变但原因从「物流破损」变成
  「质量问题」，是两个完全不同的问题，只看总量会漏掉。
