# 商品目录质量标准

商品目录（Catalog）质量是「搜索能否召回到商品」与「商品卡能否被点击」的双重前提。

## 一、三项核心质量字段

| 字段 | 标准 | 不达标的影响 |
| --- | --- | --- |
| 标题长度 | ≥ 18 字，含核心品类词 + 属性词 + 场景词 | 搜索召回不足、推荐无法匹配意图 |
| 主图数量 | ≥ 4 张（含白底图、细节图、场景图） | 首屏吸引力弱，点击率显著下降 |
| 属性填充率 | ≥ 85% | 筛选场景无法被召回，个性化推荐失效 |

**实测参照（本系统演示数据）**：
- 美妆个护：标题 11.4 字、主图 1.25 张、属性填充 36.3%
- 其他品类：标题 19~25 字、主图约 4.8 张、属性填充 86%~88%
- 结果：美妆个护 CTR 由 4.20% 跌至 2.09%，其他品类稳定在 5.45%~5.52%

## 二、失效链条

```
目录信息缺失（标题短 / 主图少 / 属性空）
      ↓
搜索与推荐的召回率下降（高意图词搜不到商品）
      ↓
曝光结构劣化：曝光量可能没变，但曝光给了「不该给的商品」
      ↓
商品卡吸引力下降 → CTR 下跌
      ↓
进店流量的购买意向也随之下降 → CVR 同步走弱
      ↓
差评集中在「描述不符」（用户带着错误预期进来）
```

这条链条说明：**CTR 下跌往往不是流量问题，而是呈现问题**。
判断依据是对比同期的其他品类——若其他品类 CTR 稳定，则可排除全站流量因素。

## 三、搜索零结果（Zero Result）诊断

搜索零结果次数放大，是高意图需求没有被承接的直接信号。

- 零结果词往往是**精准长尾词**（如「氨基酸洁面」「玻尿酸精华」「神经酰胺」），
  这类词的用户购买意图最强，零结果的损失也最大。
- 处置优先级：零结果词的搜索量 × 商品缺位程度。先补词表，再补商品。
- 短期止血手段：建立兜底词表（同义词、上位词），让零结果词先能召回近似商品。

## 四、上架卡点建议

把质量字段做成**上架硬门槛**，而不是事后巡检：

1. 标题字数 < 15 字 → 不允许上架
2. 主图 < 3 张 → 不允许上架
3. 属性填充率 < 80% → 不允许上架
4. 已上架存量商品：按曝光量降序批量补齐，优先处理高曝光低 CTR 的商品

## 五、监控指标

- 品类级 CTR 日环比：跌幅超过 15% 触发告警
- 标题/主图/属性三项达标率：按品类周度巡检
- 搜索零结果率：按关键词粒度监控，高意图词单独建告警
